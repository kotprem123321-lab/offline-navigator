    Карты городов

    Скачайте заранее, пока есть интернет (лучше по Wi-Fi). Потом всё работает без связи — даже в режиме полёта. Геолокацию на телефоне оставьте включённой.

    На iPhone: нажмите «Поделиться» → «На экран Домой» и открывайте навигатор с иконки — иначе Safari может удалить скачанные карты через 7 дней.
